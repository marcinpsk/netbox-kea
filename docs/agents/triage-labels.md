# Triage labels

The engineering skills use five canonical triage roles. This table maps each role to its GitHub label.

| Canonical role    | GitHub label      | Meaning                                 |
| ----------------- | ----------------- | --------------------------------------- |
| `needs-triage`    | `needs-triage`    | A maintainer must evaluate the issue    |
| `needs-info`      | `needs-info`      | Waiting for information from the author |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for an agent  |
| `ready-for-human` | `ready-for-human` | Requires human implementation           |
| `wontfix`         | `wontfix`         | The project will not implement the issue |

When a skill mentions a triage role, use the corresponding GitHub label from this table.

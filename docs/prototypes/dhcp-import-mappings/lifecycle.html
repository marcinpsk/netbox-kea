What the real database proved

Dependency-aware squash restored both original primary keys and the source association. The next real import reused the target. This worked for Subnets and Global Reservations, IPv4 and IPv6, with single and bulk deletion.

Iterative replay tried to restore a mapping before its target existed. The agreed design therefore requires squash for affected deletions.

Refuse unsafe actions

A fresh branch is required. An operation must roll back if it would delete a main mapping absent from its reversible history or overwrite newer main state.

Old branches keep independent read pages. Their mapping view must explain that a fresh branch is required. Live Kea writes and imports remain on main.

Transaction guards, newer-main conflicts, model exclusions and compatibility still need complete production validation. This illustration does not simulate PostgreSQL concurrency.
